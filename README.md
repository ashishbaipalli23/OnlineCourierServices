# 🚚 Online Courier Service - Java Maven Web Project

A full-stack web application for booking and managing courier deliveries. Built using **Java**, **JSP**, **Servlets**, **JDBC**, and **MySQL** with **Maven** as the build tool, following the **MVC design pattern**.

---

## 🔧 Features

- Customer registration and login
- Courier booking with dynamic cost calculation
- Payment system and payment history
- Delivery tracking for customers
- Delivery history for delivery agents
- Review system (submit/view reviews for completed orders)
- Admin panel for managing users and couriers

---

## 🛠️ Technologies Used

- Java (Servlets & JSP)
- JDBC & MySQL
- HTML, CSS, JavaScript
- Apache Tomcat
- Maven (project build management)
- Eclipse IDE
